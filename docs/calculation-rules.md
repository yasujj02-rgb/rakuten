# 実質価格の計算ルール

実装: `src/shared/pricing/engine.ts`（UI から独立した純粋関数）／テスト: `tests/unit/pricing.test.ts`

## 1. 式

```
税込商品価格 = taxFlag=1（税別）なら floor(itemPrice × (100+税率)/100)、それ以外は itemPrice
商品代金     = 税込商品価格 − クーポン値引額（参考価格のみ）
支払額       = 商品代金 + 送料                （送料不明なら「不明」）
ポイント対象 = 税抜: floor(商品代金 × 100/(100+税率)) ／ 税込: 商品代金   ※送料は対象外
各行ポイント = min( floor(ポイント対象 × 倍率%), 上限 )
実質価格     = 支払額 − 合計ポイント × ポイント評価額
実質単価     = 実質価格 ÷ 合計内容量 × 比較単位
```

## 2. ポイント行と重複計上防止

| 行 | 倍率 | 区分 | 根拠 |
|---|---|---|---|
| 通常購入 | 1% | 取得済み | 楽天市場の通常ポイント。**1 回だけ計上** |
| 商品別ポイント | (pointRate − 1)% | 取得済み | API の pointRate は通常 1 倍を含む倍率として扱う。期間外は加算しない |
| SPU 等 | (基本倍率 − 1) + SPU 追加倍率 | 概算 | 基本倍率（初期値 9 倍）は通常 1 倍を含む |
| 買い回り | 追加倍率 | 概算 | 通常 1 倍を含まない値で入力（最大 +9 が一般的） |
| 日付キャンペーン | 追加倍率 | 概算 | 5 と 0 のつく日等。条件を満たす場合のみ有効化 |
| スーパーDEAL | 還元率 − 1（含む設定時） | 参考 | 商品ごとに手動入力した場合のみ。API では取得不可 |
| 店舗独自ポイント | 入力値 | 参考 | API の pointRate に含まれない店舗キャンペーン |

例: 基本 9 倍 ＋ スーパーDEAL 20%（通常 1 倍を含む）
→ 1% + 8% + 19% = **28%**（単純加算の 29% にはならない）

## 3. 価格区分

| 区分 | 内容 |
|---|---|
| 取得済み情報に基づく価格 | API の価格・送料区分・商品別倍率 ＋ 通常 1 倍のみ |
| ユーザー設定を反映した概算実質価格（既定のランキング基準） | 上記 ＋ SPU・買い回り・日付キャンペーン |
| クーポン・追加還元を仮定した参考価格 | 上記 ＋ クーポン・スーパーDEAL・店舗独自ポイント・仮定送料 |

未確認のクーポンや還元は自動適用しない（参考価格にのみ反映）。

## 4. 端数・上限

- 各キャンペーン行ごとに小数点以下切り捨て、その後に上限を適用。
- 上限 = min(キャンペーン上限, 残り上限)。未入力は上限なし。
- 買い回りの上限初期値は 7,000pt（ユーザーが変更可能）。

## 5. 送料・税

- `postageFlag=0` → 送料 0 円。`postageFlag=1` → 金額不明。送料無料とはみなさず、ランキング本体から外し「送料不明」枠で送料を含まない参考値として表示。
- 手動入力した送料は全区分に反映。設定の「仮定送料」は参考価格のみに反映。
- 税率はカテゴリ既定（食品・飲料 8%、その他 10%）。設定・商品ごとに変更可能。

## 6. 仮定・簡略化（既知の限界）

- 1 注文 1 商品（数量 1）として計算。複数商品の同時購入による按分は考慮しない。
- SPU の各プログラムごとの上限・端数は 1 行にまとめて近似。
- 楽天の「ポイント対象金額」の正確な算出（クーポン按分・ポイント利用分の除外等）とは誤差が生じうる。
- 通常ポイント・SPU の対象を「税抜」とする既定値、スーパーDEAL の対象金額の既定値（税抜＝保守的）は、
  ⚠ 楽天公式のキャンペーンページで確認のうえ、設定画面で変更できる。

## 7. 容量解析（`src/shared/quantity/parser.ts`）

- 正規化: NFKC（全角→半角）、小文字化、`リットル`→`l` 等、`x * ✕`→`×`（数量文脈のみ）、桁区切りカンマ除去、`詰替/つめかえ`→`詰め替え`。
- マスク（数量とみなさない）: `倍 % 円 年 月 日 位 号 型 cm mm 種` 等の直前の数値、`ポイント10`、`第3類`、`1個あたり` 等。
- 型番対策: 英数字・ハイフン直後の数値は無視（`SX-500` 等）。単位も `×` も無い裸の数値は無視。
- 個数: `×N`、`N袋/個/本/缶/箱/ケース/パック/セット/ロール/P` の積。同値の重複表記は 1 回のみ。
- 判定不能: 同じ次元で異なる容量（選べる容量、本体＋詰め替え）、合計表記との矛盾、物理量が曖昧。
- 要確認: 括弧内・商品説明からの抽出、「約」付き、異常値を無視した場合、本体＋詰め替え、「1個=1回」等の代替単位。
- 異なる次元（ml と g 等）の商品は同一ランキングに混在させず「比較対象外」に分ける。
